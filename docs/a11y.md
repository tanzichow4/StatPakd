# Accessibility decisions (T18)

Every colour decision below is **pending design sign-off**. Ratios use the WCAG 2 formula on sRGB
hex values and match `web/src/styles/tokens.css` and `web/src/styles/contrast.test.ts` (AC18, AC24).
Target: 4.5:1 for text, 3:1 for icon glyphs and the focus ring.

## 1. Contrast table

step that passes on every background the test lists for that colour.

## 2. AC24: share segment text

`ShareRow` draws 11px percentage text on `var(--series-N)`. White fails 4.5:1 on 5 of the 8 series
colours, so the text colour is chosen per series index (`seriesTextColor`): white where it passes,
otherwise ink `#111`. This deliberately departs from AC21's "darken the same hue" rule, because white
text cannot be darkened and stay white. The alternative is darkening those series colours, which is a
larger visual change. Pending design sign-off (open question 1).

## 3. Hover backgrounds

Hover backgrounds are not resting text states, so they are recorded here and not asserted by the
contrast test. Pending design sign-off.

| Hover background | Muted `#6F6F6A` | Ink | Label `#73736E` | Note |
|---|---|---|---|---|
| `#E6E6E2` (IconButton) | 4.04 | 15.09 | 3.81 | x glyph is an icon, needs 3:1: passes |
| `--color-hover` `#F4F4F1` | 4.58 | 17.14 | 4.32 | muted passes; label text under 4.5 if used on this hover |
| `--color-hover-alt` `#F6F6F3` | 4.66 | 17.44 | 4.40 | as above |
| `--color-divider` `#F0F0ED` | 4.42 | 16.54 | 4.17 | as above |

Where muted or label text is on a hover surface and falls below 4.5, the shortfall is accepted for
the transient hover state only; the resting state passes.

## 4. Exemptions (touch targets and others)

Below 1024px, interactive controls are at least 40px tall and wide (AC6). At 1280px the visual sizes
match the design (AC7), so these desktop controls are under 40px (measured in T16):

| Control | Measured size |
|---|---|
| League buttons | under 40px (as designed) |
| Players/Teams switch | 29px tall |
| Season select | under 40px (as designed) |
| Remove x | 26px |
| Compare/Team breakdown switch | 31px |
| Team chips | 31px |
| Done button | 38px |
| Stat checkbox rows | 32px |
| Add popover position chips | 26px (1280 only) |
| Add-stat menu items | 31px (1280 only) |

Other exemptions:
- Share-of-production segments: their width encodes data.
- Focusable scroll and chart regions (compare table, roster table, charts): larger than 40px anyway.
- Disabled text: nav "Soon" buttons (`--color-nav-soon` on ink, 3.48), the locked last-stat checkbox
  (`--color-checkbox-off` on white) and the disabled add button at opacity 0.4 (WCAG 1.4.3 exempts
  disabled controls).
- `--color-chart-muted` `#C9C9C4` for unselected 3D points: 1.66 on white. These are decorative
  context, not text or the sole carrier of information; selected points use series colours.

## 5. Non-colour series encoding proposal (AC16, not implemented)

Series are currently told apart by colour only; names are available as text in tables, the radar
sr-only list and share segment names. Proposal for a later ticket:
- Radar: a distinct dash pattern per series index (solid, dashed, dotted, dash-dot, then repeating).
- 3D scatter: marker shapes by series index: circle, square, triangle, diamond, then repeating.
