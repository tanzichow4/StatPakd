1StatPakd — three directions. All share live state: pick players/teams, toggle stats, switch Table / 2D / 3D. Drag the 3D chart to rotate.
Assumptions. NFL only for now; leagues live in a switcher so NBA/MLB/etc. slot in. Stat sets are defined per league + entity type (players vs. teams). Up to 4 entities compared at once.
System. White surfaces, black for selection & emphasis, hairline gray borders. Geist + Geist Mono for numbers. Four series colors only (black, red, blue, green) so charts stay readable.
Data. Numbers shown are sample values for layout only — wire to a real stats API in implementation.
